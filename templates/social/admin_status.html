{% if instagram.connected %}Replace token{% else %}How to connect (about 15 minutes, once){% endif %}
  1. The Instagram account must be a Business or Creator account (Instagram app → Settings → Account type).
  2. Go to developers.facebook.com/apps → Create app → use case “Manage messaging & content on Instagram”.
  3. In the app: Instagram → API setup with Instagram login → Add account, and sign in as the farm’s Instagram.
  4. Click Generate token next to the account, copy it, and paste it below. You don’t need to publish the app or submit it for review.

{% include "social/admin_account.html" with a=facebook %}
{% if facebook.connected %}Replace token{% else %}How to connect{% endif %}
  1. In the same Meta app, add the Facebook Login / Pages use case, then open the Graph API Explorer.
  2. Choose the app, then Get Page Access Token with the pages_read_engagement and pages_show_list permissions, and pick the farm’s Page.
  3. In the Access Token Debugger, click Extend Access Token, then run me/accounts in the Explorer with that long-lived token — the Page’s access_token and id there don’t expire.
